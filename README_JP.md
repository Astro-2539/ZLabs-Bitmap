Z Labs Pixel 12pxは、仕様が11*12pxのピクセルフォントで、サンセリフ体の字形スタイルを採用しており、中国大陸、香港、日本の3種類の異体字を備え、欧文フォントは等幅仕様で設計されています。

このフォントは現在、簡体字中国語、繁体字中国語、日本語の日常使用に基本的に対応しています。

## 字形の異体

本フォントには、CN（中国大陸基準に準拠）、HC（香港基準に準拠）、JP（JIS X 0213:2004基準に準拠）の3種類の異体があり、異なる環境での使用ニーズに対応しています。

> [!IMPORTANT]
> 
> 地域によって用字習慣が異なるため、適切な字形異体を選択することが非常に重要です。簡体字中国語環境ではCN異体、繁体字中国語環境ではHC異体、日本語環境ではJP異体を選択することを推奨します。
>
> 繁体字中国語ユーザーの方で、香港の字形基準を受け入れられない場合は、他のフォントの使用を推奨します。
>

#### フォントフォールバック

作者の精力に限りがあるため、現時点でHC版とJP版は一部の漢字のみ制作されているため、使用中に漢字が欠落する場合があります。

ソフトウェアが複数フォントの排版をサポートしている場合は、`font_family`または類似のプロパティを設定することで、漢字のサポート数がより多いCN異体をHC/JPのバックアップフォントとして使用し、HC/JPが未サポートの漢字をCN異体で表示させることができます。

ソフトウェアが複数フォントをサポートしていない場合は、対応する異体の`Fallback`（FB）バージョンの使用を検討してください。このバージョンでは、HC/JP異体がサポートしている漢字については原状を保持し、CN異体が制作済みでHC/JPが未制作の漢字については、CN字形を対応するコードポイントに填充します（当該文字がHC/JPの制作計画内にあるか否かに関わらず）。これにより、サポートする漢字数がCN版と同じになります（字形の正確性は保証されません）。

## エンジニアリングファイルからのフォント構築

本フォントは[Bits'n'Picas](https://github.com/kreativekorp/bitsnpicas)を使用して制作されています。`./tools/build.py`を実行することでフォントを生成できます。

構築プロセスは`fonttools`ライブラリ、`pixel_font_builder`ライブラリ、`kbitfont`ライブラリに依存しています。

構築プロセスの詳細については、`Tools`フォルダ以下のREADMEファイルを参照してください。
